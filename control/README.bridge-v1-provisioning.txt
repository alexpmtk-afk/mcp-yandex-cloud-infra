Yandex Cloud ↔ Google Drive Bridge v1 runtime provisioning is controlled by the workflow provision-google-drive-bridge-v1-lockboxes.yml. Creating or updating control/provision-google-drive-bridge-v1-lockboxes.txt on main triggers an idempotent reconciliation of the dedicated Marketplaces and Birzha Lockboxes. No secret payload and no production binding are created by that reconciliation.
